# Personal blog

Source code of my personal blog page, hosted on [blog.miloszgilga.pl](https://blog.miloszgilga.pl). Created using
Next.js in SSG mode, Nextra and KaTeX. Hosted on Vercel PaaS.

## Tech stack

* Next.js SSG,
* Nextra,
* KaTeX (LaTeX for web),
* PaaS provided by Vercel.
